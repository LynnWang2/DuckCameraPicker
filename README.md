# 识色鸭（Duck Camera Picker）

以取色鸭桌面端 UI 为原型（黄鸭图标、大黄渐变按钮、暖色深浅主题、中文颜色命名），
用 Flutter 重写的**相机实时取色**应用：把手机对准任何物体，中央准星实时识别颜色，
点「确认取色」即保存到历史并复制色值。

## 功能

- **底部标签栏**：高级高斯模糊圆角矩形底 + 简约黑色图标（深色模式为白色图标），选中项浅灰圆角高亮
- **相机实时取色**：中间标签页常驻，全屏预览 + 中央取色点，约 8fps 实时刷新当前颜色；切到其他页自动暂停以省电
- **定格取色**：标签栏上方的相机按钮按下定格画面，变成 X 按钮后按下回到实时取色
- **双指缩放**：缩放相机画面，缩放时显示放大倍数（如 2.5×）
- **磨砂颜色卡片**：相机按钮上方，高斯模糊大圆角矩形；左边色块 + 中文颜色名 + 色值，右边蓝色保存按钮，一键存入取色历史
- **中文颜色命名**：算法直接移植自桌面端（`color_name`），两端命名一致
- **显示格式**：我的页点开圆角矩形单选框切换（HEX 含/不含 #、RGB、HSL、CMYK），取色页与历史复制都跟随该格式
- **取色历史**：独立标签页，最近 50 条持久化保存；点按复制色值，左滑删除，一键清空
- **我的**：应用图标、取色设置（显示格式 / 软件外观，均为圆角矩形单选框）、关于
- **外观**：跟随系统 / 浅色 / 深色；浅色为浅灰底 + 白卡片（无描边、浅投影），深色为灰黑底 + 深灰卡片
- **沉浸式状态栏**：内容延伸进系统栏，全透明
- **应用图标**：小鸭启动图标（Android 传统 + 自适应图标，iOS 全尺寸）
- **闪光灯**：取色页右上角可开关补光灯

## 运行

```bash
flutter pub get
flutter run
```

## 平台配置（已完成）

- iOS：`ios/Runner/Info.plist` 已添加 `NSCameraUsageDescription`（识色鸭需要使用相机进行实时取色）
- Android：`android/app/src/main/AndroidManifest.xml` 已添加 `CAMERA` 权限 + `android.hardware.camera` feature

相机权限由 `camera` 插件在运行时申请，拒绝后页面会显示重试入口。

## 实现说明

- 取色点固定为**画面中心**：避开预览旋转 / 前后摄镜像的坐标映射坑，
  中心点在任何方向下都是稳定的。交互上移动手机对准颜色即可
  （桌面端的放大镜跟随鼠标，移动端的对等物就是准星取色）。
- Android 相机帧为 YUV420，iOS 为 BGRA8888，`lib/camera/frame_sampler.dart`
  中双路处理，中心 5×5 平均降噪。
- 应用锁定竖屏（`main.dart`），保证预览与采样坐标一致。


## 已知限制

- 实时取色依赖相机帧流，中低端机连续取色时会有轻微发热
- 未做点击画面任意位置取色（见上：中心准星方案更稳）
